#Земля

Особенности Стихии: Лучшая из стандартного набора для наложения баффов
Свойства: *Преобразования, стойкость*
**Психология**
	

**Аспекты Стихии**
> Земля, Природа(*растения*), металл, кристалл

**Родной Мир** - Гейя

##### Заклинания
###### 1 Ранг

|      Название       | Описание                                                                           |
| :-----------------: | ---------------------------------------------------------------------------------- |
| Агрессивная поросль | Создает растение, атакующее врага                                                  |
|      Камнепад       | Наносит урон случайными камнями на местности                                       |
|     Спокойствие     | Усмиряет зверя                                                                     |
|  Терновый пленник   | Спутывает цель                                                                     |
|     Мятный чай      | Снимает негативные эффекты, излечивает от легких болезней и слабого яда            |
|   Звериные черты    | Прибавляет от +1 до +3 к определенной характеристике, связанной с некоторым зверем |
|      Удобрение      | Восстанавливает поврежденные растения                                              |
|   Хвойный оберег    | Исцеляет цель и иногда дарует одноразовую "удачу"                                  |
|    Призыв: "фея"    | Призывает мелкое летающее существо                                                 |
